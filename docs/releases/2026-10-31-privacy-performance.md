# Privacy policy: app performance diagnostics, 2026-10-31

RoRadio 2.3.1 measures how the app performs in the field (the owner: every measurement from the field), so
`privacy.html` gets one more row in its diagnostics table:

- how long RoRadio takes to start (process start to the first page on screen);
- how long it takes to find a song's year in Apple Music's catalogue, and how the lookup ended, never the song;
- the size the window was left at, rounded down to 100 pixels, with the display scale and whether it was maximized.

All of it travels only with diagnostics on (Settings › Send anonymous diagnostics), like every other row. The date at
the top moves to 31 October 2026.
