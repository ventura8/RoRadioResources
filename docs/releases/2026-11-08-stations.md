# Station fixes, 2026-11-08

Five stations that RoRadio 2.4.0 listeners could not start (Sentry, last 14 days: almost every start ended in
`PlayFailed` with `cause:unsupportedCodec`) get a working stream url. Every RoRadio app downloads the list from GitHub
Pages, so the fix reaches listeners without an app update. Urls only: no GUID, title, category or logo changed.

Each new url was probed from Romania with `scripts/Test-StationStreams.ps1` (verdict `alive`) and read for 64 KB of
audio through .NET's `HttpClient`, the client the app's playback buffer uses (MP3/ADTS frame sync at the start).

## Why "alive" stations failed

The old urls of Radio Caprice Dream Trance and Paprika Rádió are SHOUTcast 1.9.8 servers, which answer
`ICY 200 OK` instead of an HTTP status line. The probe reads that (it retries as HTTP/0.9), but .NET's `HttpClient`
refuses it ("Received an invalid status line: 'ICY 200 OK'"), so RoRadio's playback buffer, on by default since
2.3.0, cannot open them and the player reports the source as unsupported. Both stations also stream from a current
server, which the new urls use.
