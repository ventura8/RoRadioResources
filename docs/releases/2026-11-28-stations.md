# Station fixes, 2026-11-28

Sentry showed three stations that RoRadio 2.5.1 and 2.5.2 listeners could not start: every failure came before
any audio. Two now have a working url. The list carries urls only: no GUID, title, category or logo changed.

Each new url was probed from Romania with `scripts/Test-StationStreams.ps1` (verdict `alive`). It was also played
through Windows' own media player (`Windows.Media.Playback.MediaPlayer`, state `Playing`, position past 1 s).
